# SmarType icon kit

The approved SmarType logo: a white key on a blue → cyan → mint gradient, the S with voice bars in its tail, and the AI spark in the key's top-right corner. How it's built and the spark rules: the Brand page of the design site (`site/brand.html`).

Everything here is generated by `tools/build_icon_kit.py` from `src/brand_marks.py`. Don't edit the files by hand; change the source and rebuild.

## Android (`android/`)

| File | Use |
| --- | --- |
| `drawable/ic_launcher_background.xml` | Adaptive icon background: the gradient and its soft light |
| `drawable/ic_launcher_foreground.xml` | Adaptive icon foreground: the key, the S with voice bars, the spark |
| `drawable/ic_launcher_monochrome.xml` | Themed icon (Android 13+). Android tints it |
| `drawable/ic_launcher_foreground_debug.xml`, `…_beta.xml` | The foreground with a DEV or BETA badge |
| `mipmap-anydpi-v26/ic_launcher.xml`, `ic_launcher_round.xml` | Release launcher icon |
| `mipmap-anydpi-v26/ic_launcher_debug*.xml`, `ic_launcher_beta*.xml` | Debug and beta launcher icons |
| `drawable/ic_stat_smartype.xml` | Status-bar icon (24 dp, white, solid S) for notifications |
| `drawable/ic_smartype_splash.xml` | Splash icon for `windowSplashScreenAnimatedIcon` |

minSdk is 26, so no PNG launcher icons are needed.

Where they go in the app:

- Copy the files into `app/src/main/res/` (same folder names).
- They replace `ic_smartype*`, `ic_app_icon_stable*`, `ic_app_icon_debug*` and `ic_app_icon_beta*`. Point `android:icon` and `android:roundIcon` in the manifest at `@mipmap/ic_launcher` and `@mipmap/ic_launcher_round`. Debug and beta builds use the `_debug` and `_beta` icons, the way they use `ic_app_icon_debug` and `ic_app_icon_beta` today.
- Splash: `windowSplashScreenAnimatedIcon` → `@drawable/ic_smartype_splash`. Background: Porcelain `#F7F9FA` in light theme, Graphite `#0D1114` in dark.
- Notifications: `setSmallIcon(R.drawable.ic_stat_smartype)`.
- The AI logo `ic_ai_logo` (three stars) is retired. Use the AI badge from the Brand page: the spark (`spark.svg`) in Ink `#08323B` on the AI gradient.

## Play Store (`png/`)

- `play-store-icon-512.png`: 512 × 512, 32-bit PNG, full square. Play applies its own rounded mask.
- `icon-rounded-1024.png`, `logo-480.png`: the icon with rounded corners, for documents and slides.
- `lockup-ink.png`, `lockup-porcelain.png`: the icon with the wordmark, on light or dark.

## Web (`web/`)

`favicon.svg`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `site.webmanifest`.

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-32.png" sizes="32x32">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
```

## Masters (`svg/`)

- `icon.svg` (full square), `icon-rounded.svg`, and each layer: `icon-background.svg`, `icon-foreground.svg`, `icon-monochrome.svg`, `icon-notification.svg`.
- `wordmark-ink.svg`, `wordmark-porcelain.svg`, and the `-gradient-t` versions with the T in the gradient.
- `lockup-ink.svg`, `lockup-porcelain.svg`: icon height = 1.6 × the cap height; gap = half the icon.

All text is outlined, so no font is needed to use them.

## Fonts and licence

The S and the wordmark are outlined from Google Sans Flex (SIL Open Font License): the S at weight 700 and roundness 100, the wordmark at weight 600 and roundness 100. The OFL allows this; don't use the "Google" or "Google Sans" names with SmarType.

## Rebuilding

```bash
python tools/build_icon_kit.py --font path/to/GoogleSansFlex[ROND,opsz,slnt,wdth,wght].ttf
```

Needs fontTools, skia-pathops, uharfbuzz, Pillow and Google Chrome. The font is on github.com/google/fonts under `ofl/googlesansflex`.
