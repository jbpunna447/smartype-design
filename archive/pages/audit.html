4 · Design system addendum

Changes the design system needs so it matches Fix 1b and Fix 4. Until the design system page is updated, these rows win.

ComponentChange
KeyboardPanelHeader: ‹ and the panel name, then an optional badge ("4 left") and one icon action. No keyboard-icon toggle, no ABC key. The smartbar stays visible above the panel with the open panel's button highlighted; tapping another smartbar button switches panels. Selection hint only when part of the text is selected. Dock: content actions only (Copy, Replace, Insert); an unavailable state has no dock.
Smartbar (new)Fixed order: Rewrite, Translate, Format, Clipboard, Notes, [Emoji], ⋯, Mic. Rewrite, Translate, Format and Mic use the AI gradient as round icon buttons; the others are plain. Emoji only when there's room and the keyboard has no emoji key. Every icon has a spoken label and a long-press name.
Suggestion rowAlways present at a fixed height, empty when there's nothing to suggest. Also hosts keyboard messages ("Replaced · Undo", "Inserted · Undo") for 6 s.
Colour (AI gradient)Reserved for AI: Rewrite, Translate, Format, the Mic, voice Done, Replace and Insert of an AI result, and Upgrade. "One Ai button per screen" applies to labelled buttons.
BannerAdd Warning (amber container) for "limited but nothing failed", such as "Premium isn't available on this phone".
Voice bar (new)Replaces the smartbar while recording: Delete, recording dot and timer, waveform, language chip, ✓ Done. Transcribing state: progress with the detected language.
