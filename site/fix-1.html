Decisions for the owner

DecisionRecommendation
When text leaves the phoneThe ✦ tap is the explicit action (replacing the Rewrite tap in today's rule). Blocked in password fields and incognito, as now.
Where results are keptIn memory only, for this text and this panel session. Never written to disk, never logged.
How usage is countedOne ✦ tap = one use, however many styles it returns. Needs a server change: today every request reserves one use (functions/src/quota.ts), and the free allowance is a one-time trial (AI_FREE_TRIAL_LIMIT, default 5), not a monthly one. Without batching, auto-running on open would spend a trial use every time ✦ is tapped.
How many styles per requestFix grammar plus the pinned styles (the pin limit is 4, AI_PINNED_STYLES_LIMIT). Others on demand. Today the server takes one style per request (styleId), so this is new backend work.

Acceptance criteria

  • Tapping ✦ with text sends exactly one request and shows the preselected style's result; there is no Rewrite button.
  • Switching between pinned style chips after results arrive sends no further requests and shows each result instantly.
  • Editing the text, ‹ or Back discards the stored results; nothing is written to disk.
  • Every request ends in results or an error banner; the panel never closes by itself (20 tries on a slow network, airplane mode toggled mid-request).
  • An empty field sends nothing and shows "Type something first".
  • While the panel is open, the header shows ‹ and the panel name; ‹ and system Back return to the letter keys from every state, and the keyboard stays visible.
  • Undo after Replace restores the original text exactly, within 6 s, and does nothing if the user typed in between.
  • Password fields and incognito send nothing.
  • One ✦ tap counts as one use on the server, and a failed request counts as none.
  • No log, analytics event or crash report contains the text or any result.
