AI rewrite

Tap ✦ and the result is there (Premium) or one tap away (free); switch styles instantly; never lose the user's words.

New screens are drawn at real size: 1 px = 1 dp on a 360 × 800 dp phone. Open "Spec" under any screen for sizes, tokens and icons.

The problem

You type, tap ✦, and get a panel that repeats your message in a quote box, waits for you to pick a style and tap Rewrite, and hides the style chips once a result shows (B1, B2, B3).

A rewrite can fail silently (A2). Replace has no Undo (A5). System Back closes the whole keyboard (A9), and the way back is an ↵ icon that looks like Enter (A10). The chosen style isn't remembered (A3), and a ✅ on the Grammar fix chip reads as "done" (A4).

Done when

  • Premium: tapping ✦ with text sends exactly one request and shows the preselected style's result; there is no Rewrite button.
  • Free users: tapping ✦ sends nothing; Rewrite sends one request for all styles and counts as one try.
  • Switching between style chips after results arrive sends no further requests.
  • Stored results are dropped when the text changes or the keyboard closes; nothing is written to disk.
  • Every request ends in results or an error banner; the panel never closes by itself (20 tries on a slow network, airplane mode toggled mid-request).
  • While a panel is open it replaces the smartbar and the keys; ‹ and system Back bring them back from every state, and the keyboard stays visible.
  • Undo after Replace restores the original text exactly within 6 s, and does nothing if the user typed in between.
  • Password fields and incognito send nothing.
  • One ✦ tap counts as one use on the server; a failed request counts as none.
  • No log, analytics event or crash report contains the text or any result.
For developers

Decided

QuestionDecision
Premium: tapping ✦ sends the text straight awayYes. Blocked in password fields and incognito, as now.
Free users: tapping ✦Opens the panel without sending. A Rewrite button sends one request for the selected style and the pinned styles.
How many tries one Rewrite tap counts for free usersLater, not blocking. Until then: one tap = one try; opening the panel and switching styles cost nothing.
Results kept in memory onlyYes: until the text changes or the keyboard closes. Never written to disk, never logged.
All styles in one request, counted as one useYes. It's also cheaper: the text and the instructions are sent once instead of once per style, with one round trip. Needs a server change (today the task takes one styleId and every request reserves one use).
